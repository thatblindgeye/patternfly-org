Generate accessibility documentation for PatternFly components.

## Quick Commands

**Generate docs for a component:**
Generate accessibility documentation for the [ComponentName] component

**List missing documentation:**
Which PatternFly components are missing accessibility documentation?

**Analyze a component:**
Analyze the accessibility requirements for the [ComponentName] component

**Review existing docs:**
Review and enhance the [ComponentName] accessibility documentation

## Scripts Available

All scripts are located in `scripts/`:

- `generate_a11y_docs.py` - AI-powered generation (requires Anthropic API key)
- `generate-a11y-docs.js` - Template-based generation
- `demo_a11y_generator.py` - Demo without API calls
- `QUICKSTART-A11Y-GENERATOR.md` - Quick start guide
- `README-A11Y-GENERATOR.md` - Full documentation
